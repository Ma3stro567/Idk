# Chess Bot (Android, Stockfish)

Бот читает доску с экрана, считает ход через Stockfish 17.1 и показывает поверх экрана
стрелку: **1 — по какой фигуре тапнуть, 2 — куда**. Может сам делать эти два тапа.
Использовать только в своих играх / против ботов / с согласия соперника.

## Как получить APK
GitHub → вкладка **Actions** → последний запуск «Build APK» → Artifacts → `ChessBot-apk`
(или раздел **Releases** → `latest-apk`). Установи APK на телефон (arm64).

## Как пользоваться
1. Открой приложение: «Разрешить оверлей» и включи службу «Chess Bot» в спец. возможностях.
2. Выбери Эло (2800 по умолчанию, 0 = максимум), время на ход, цвет, авто-тапы.
3. «Запустить бота» → разреши запись экрана.
4. Открой шахматы с партией, где доска видна целиком. Калибровка не нужна: бот сам найдёт доску.
5. В **начале новой партии** жми **Старт**. Бот запомнит вид фигур и начнёт играть.

Ограничения: стартовать нужно с начальной позиции; доска должна быть целиком видна и не двигаться;
подсказки легальных ходов/сильные подсветки темы могут сбивать распознавание — отключи их в настройках шахмат.

## Встроенные фигуры
Вид фигур chess.com (зелёная доска) вшит в приложение (`app/src/main/assets/templates_chesscom.bin`), поэтому
запускать бота можно в любой момент партии. Для других тем бот сам запоминает фигуры из начальной позиции.

## Обновление без удаления
Все сборки подписываются одним постоянным ключом (`app/keystore/chessbot.jks`, пароль в `app/build.gradle.kts`),
а номер версии растёт с каждой сборкой, поэтому новый APK ставится поверх старого. Если у тебя стоит сборка,
сделанная ДО этого изменения, её нужно один раз удалить (у неё был другой случайный ключ).
