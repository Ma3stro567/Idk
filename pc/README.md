# Chess Bot для ПК (Windows)

То же, что и телефонная версия: находит доску на экране, считает ход Stockfish 17.1, рисует поверх экрана
стрелку «1 — откуда, 2 — куда» и (по желанию) сама кликает мышью. Для игры против ботов / в своей игре.

## Как получить
GitHub → **Releases** → `latest-pc` → `ChessBot.exe` (один файл, Stockfish внутри).
Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

## Как пользоваться
1. Запусти `ChessBot.exe`, выбери силу (Эло), время на ход, паузу «от–до», цвет (по умолчанию «Авто»).
2. Открой партию. Если хочешь пользоваться ПК, пока бот играет, выбери в списке **«Окно с доской»** своё окно
   (браузер с партией; список обновляется кнопкой ⟳). Бот снимает только это окно, **даже если его закрыли другие
   окна** (оно не должно быть свёрнуто), а режим **«Фоновые»** клики идёт в окно без движения твоего курсора.
   **Chrome/Edge:** фоновые клики Windows им не подходят. Нажми **«Запустить Chrome для бота»**: откроется Chrome
   с отдельным профилем (в нём один раз войди в chess.com), выбери в списке **«Chrome (режим бота)»** — бот снимает
   вкладку и кликает прямо в неё через протокол отладки Chrome, твоя мышь и клавиатура свободны, окно можно
   закрыть другими окнами или свернуть.
   Для других приложений: если фоновые клики не срабатывают, выбери **«Мышью»**: бот вынесет окно вперёд, кликнет и вернёт
   курсор на место. «Весь экран» — как раньше: доска должна быть видна на основном мониторе целиком.
3. Нажми «▶ Мой ход» (или «▶ Его ход», если сейчас ходит соперник).
   Бот сам найдёт доску и твой цвет. Стартовать можно в любой момент партии.
4. «⏸ Пауза» — бот ничего не делает. Чтобы продолжить, снова нажми «▶ Мой ход» / «▶ Его ход»: доска будет
   прочитана заново. В режиме «Мышью» можно ещё резко увести мышь в угол экрана (аварийный выход pyautogui).

Настройки и запомненный вид фигур лежат в `C:\Users\<ты>\ChessBotPC\`.
Вид фигур chess.com вшит; для других тем бот сам запоминает фигуры из начальной позиции.

Проверка распознавания без экрана: `python chessbot_pc.py --selftest скриншот.png`.
